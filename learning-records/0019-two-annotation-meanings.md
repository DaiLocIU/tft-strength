# 0019: Two Annotation Meanings

## Date

2026-08-26

## Lesson

The word `annotation` has two meanings in this project.

## Key Insight

Label Studio annotations are dataset labels that describe images. Python type annotations are code hints that describe values for static type checkers.

## Practice

- Read `task["annotations"]` as Label Studio data.
- Read `task: TaskItem` as Python type information.
- Keep the two meanings separate while refactoring the dataset script.
