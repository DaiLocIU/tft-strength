## Date

2026-08-26

## Lesson

The learning approach changed from generated scaffold to empty-code guidance.

## Key Insight

For this user, learning is stronger when the agent provides the next small concept and the user writes the code manually.

## Practice

- Keep project code mostly empty.
- Start by writing the Label Studio config by hand.
- Move to Python only after the labeling config is understood.
