# TFT Board Detector

This folder is intentionally almost empty.

You will write the Python code step by step while learning computer vision and object detection.

First target:

- detect one class: `board`
- use Label Studio for annotation
- convert Label Studio labels to YOLO format
- train only after you understand the label conversion

## Empty Structure

```text
vision-board-detector/
  data/raw/                  put TFT screenshots here
  exports/label-studio/      put Label Studio JSON export here
  label_studio/              Label Studio config you will write
  scripts/                   Python scripts you will write
  src/board_detector/        Python package you will write
```
