TFT Board Detection Workflow

A compact reference for the first computer vision loop: screenshot, label, convert, train, predict.

One-Class Detector

The first model should detect exactly one object class: board. Do not label champions, bench units, items, UI buttons, or hexes yet.

Folder Flow

vision-board-detector/
  data/raw/                  full screenshots
  exports/label-studio/      Label Studio JSON exports
  datasets/tft-board-yolo/   generated YOLO dataset
  runs/                      training output
  board_detection/           Python package
  scripts/                   command-line scripts

YOLO Box Format

Each label file has one line per object:

class_id center_x center_y width height

For this project, class_id is always 0, because board is the only class. Coordinates are normalized from 0.0 to 1.0.

Good First Dataset

  • Start with 30 screenshots.
  • Use different rounds and board skins if possible.
  • Draw one rectangle around the playable board region.
  • Keep labels consistent. Consistency beats precision early.
  • Reserve about 20% of images for validation.
