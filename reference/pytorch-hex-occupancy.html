PyTorch Hex Occupancy Reference

Use PyTorch only for the question each known hex crop asks: occupied or empty?

Keep This Pipeline

screenshot → board detector → board crop → known hex centers
→ one hex crop → PyTorch classifier → occupied / empty

The detector and hex geometry find where to look. The classifier decides what state the crop shows.

Folder Labels

data/hex-occupancy/
  train/
    empty/
    occupied/
  val/
    empty/
    occupied/

torchvision.datasets.ImageFolder derives labels from these folder names. Keep the same class folders in train and validation.

Core Objects

ObjectJob in this project
ImageFolderMaps each crop file to the folder label.
DataLoaderFeeds batches of crops and labels into training.
model logitsProduces two unnormalised scores: one per class.
CrossEntropyLossCompares those scores with the correct integer label.
validation splitChecks whether the model generalises to unseen screenshots.

Minimal Data Load

from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.Resize((160, 160)),
    transforms.ToTensor(),
])

train_set = datasets.ImageFolder("data/hex-occupancy/train", transform=transform)
train_loader = DataLoader(train_set, batch_size=32, shuffle=True)

print(train_set.classes)  # e.g. ['empty', 'occupied']

Always inspect train_set.classes. The numerical labels follow alphabetical folder order, not your intuition.
