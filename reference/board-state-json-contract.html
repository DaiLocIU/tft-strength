Board State JSON Contract

A board-state contract is the stable data shape that later code can read without looking at the review image.

One Board

{
  "image_name": "image_388.png",
  "champion_conf_threshold": 0.5,
  "identity_padding": 0.08,
  "units": [
    {
      "row": 2,
      "column": 0,
      "champion": "warwick",
      "identity_confidence": 0.99,
      "champion_box_confidence": 0.88,
      "source": "both"
    }
  ]
}

Rules

One occupied champion hex should produce one unit row. Empty hexes can stay out of the output unless a later feature needs them.

Why JSON

JSON is easy for Python, JavaScript, and future app code to read. Python's standard json module can serialize dictionaries and lists directly.
