Labeling TFT Board Reference

A one-page checklist for creating consistent Label Studio board annotations.

Label Config

<View>
  <Image name="image" value="$image"/>
  <RectangleLabels name="label" toName="image">
    <Label value="board" background="#FF0000"/>
  </RectangleLabels>
</View>

What To Draw

Draw exactly one rectangle around the playable combat board area. Include the whole board surface, even if some cells are empty.

What Not To Draw

  • Do not include the bench.
  • Do not include the shop.
  • Do not include the left trait panel.
  • Do not include the top stage/round UI.
  • Do not draw boxes around champions.

Consistency Rule

If the board edge is visually unclear, prefer the same approximate boundary every time. A slightly imperfect but consistent dataset is easier for a model to learn than a dataset where every image uses a different definition.

100-Image Batch Plan

  • Images 1-10: label slowly and define your personal boundary rule.
  • Images 11-70: label normally using the same rule.
  • Images 71-90: add variety: different rounds, units, effects, and board states.
  • Images 91-100: review earlier labels and fix obvious inconsistencies.

Quality Check

Every image should answer yes to these questions:

  1. Is there exactly one board rectangle?
  2. Does it exclude the bench and shop?
  3. Does it include the whole playable board?
  4. Would I draw the same box tomorrow?

Label Studio's RectangleLabels result stores x, y, width, and height as 0-100 values. Source: Label Studio RectangleLabels documentation.
