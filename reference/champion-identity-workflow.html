Champion Identity Workflow

Reuse the current one-class champion detector to crop units, then train a classifier that answers which champion is inside each crop.

Pipeline

board crop
  -> champion detector finds boxes
  -> crop each champion box
  -> human labels crop folder name
  -> classifier learns champion identity
  -> mapped hex gets champion name

Dataset Shape

data/champion-identity/
  train/
    kayle/
    nunu/
  val/
    kayle/
    nunu/

First Rule

Start with two or three champion names only. A small clean classifier is more useful than a large noisy one.

Do Not Start With Stars

Star level is a smaller visual signal than champion identity. Train identity first, then add star level after the box-to-name path works.

Primary reference: Ultralytics classification dataset.
