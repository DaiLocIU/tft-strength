Champion Foot Hex Choice

When a detected champion overlaps multiple hexes, assign the champion signal to the occupied hex closest to the champion's bottom-center point.

Rule

champion box exists
  -> compute bottom-center point
  -> find occupied hex centers inside the box
  -> if any exist, choose the one nearest bottom-center
  -> otherwise choose the nearest hex overall

Why

A large champion's body can cover several hexes, but its board position is usually represented by the feet/base area. Object detection gives the box; hex occupancy gives local board evidence. The final choice should use both.

Python Shape

point_x = (box["x1"] + box["x2"]) / 2
point_y = box["y2"]

occupied_candidates = [
    hex_cell
    for hex_cell in hexes
    if hex_is_occupied(hex_cell)
    and box_contains_hex_center(box, hex_cell)
]

if occupied_candidates:
    chosen_hex = nearest_hex(point_x, point_y, occupied_candidates)
else:
    chosen_hex = nearest_hex(point_x, point_y, hexes)

Fallback Meaning

The fallback is important: if the occupancy classifier misses the standing hex, the champion detector can still mark one hex as occupied.

References: Ultralytics object detection, Red Blob hex grids.
