Champion Name To Hex Pipeline

The final board-state row is built by joining three signals: detected champion box, chosen board hex, and classified champion name.

Data Flow

board crop image
  -> champion detector
  -> champion boxes
  -> choose one hex for each box
  -> crop each champion box
  -> identity classifier
  -> row, column, champion, confidence

Detector Output

{
  "x1": 120.0,
  "y1": 80.0,
  "x2": 220.0,
  "y2": 260.0,
  "confidence": 0.82
}

Classifier Output

{
  "champion_name": "warwick",
  "identity_confidence": 0.91
}

Joined Output

{
  "row": 3,
  "column": 4,
  "occupied": true,
  "champion_name": "warwick",
  "champion_confidence": 0.82,
  "identity_confidence": 0.91
}

Important Rule

Classify the same box that was mapped to the hex. Do not classify the whole board crop.

Sources: Ultralytics detection task and Ultralytics classification task.
