Start Hex Grid From Empty Code

We removed the generated hex script. Now you will rebuild it step by step, starting with the smallest useful object: one hex cell center.

Today’s goal is not to draw perfect hexes. Today’s goal is to create a typed data shape for one board cell.

The Mental Model

The TFT board has 28 playable cells. That is 4 rows x 7 columns. Before drawing polygons, detecting units, or doing geometry, your code needs a way to describe one cell. 

one hex cell =
  row number
  column number
  center x position
  center y position

Create The Empty File

Create this file:

vision-board-detector/scripts/detect_hexes.py

Write Only This First

from typing import TypedDict


class HexCell(TypedDict):
    row: int
    column: int
    center_x: float
    center_y: float

Why This Shape?

row and column tell you which TFT slot this is. Later, that lets you say things like “there is a unit at row 2, column 5.”

center_x and center_y tell you where that cell lives inside the cropped board image.
