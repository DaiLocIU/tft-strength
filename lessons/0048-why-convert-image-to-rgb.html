Why convert("RGB")?

Image.open(image_path) loads an image in whatever pixel format the file uses. convert("RGB") makes that format predictable before drawing.

For your hex overlay code: RGB means every pixel has red, green, and blue channels, so drawing "red" or "white" behaves normally.

Image Mode

Pillow images have a mode. The official Pillow docs describe RGB as true color with three 8-bit channels, and RGBA as RGB plus an alpha transparency channel. Pillow image modes 

image = Image.open(image_path)
print(image.mode)

Why Normalize?

Your overlay function wants a simple color image. If the file is grayscale, palette-based, or has transparency, drawing can behave differently or save differently. Converting to RGB gives the rest of your function one stable assumption. 

image = Image.open(image_path).convert("RGB")

What It Does Not Mean

It does not resize the image. It does not detect anything. It does not change coordinates. It only changes how each pixel stores color.

In Your Code

image = Image.open(image_path).convert("RGB")
draw = ImageDraw.Draw(image)

Read this as: “open the board crop, make it a normal color image, then prepare to draw on it.”
