What To Do After First Good Detections

A good screenshot is not the finish line. Now you inspect many predictions and decide what kind of problem remains.

Right Now

Your model has passed the first useful test: it can detect the board with high confidence on at least one unseen screenshot.

Next Action

.venv/bin/yolo detect predict \
  model=runs/detect/train-20/weights/best.pt \
  source=data/raw \
  project=runs/detect \
  name=review-raw

This creates prediction images for many raw screenshots. Your job is to review them like a dataset doctor.

If Results Are Good

one box
high confidence
board only
no bench
no side UI
works across different videos/maps

Then do this:

  1. Create a real train/val split.
  2. Train again with validation images separated.
  3. Test on new unlabeled screenshots.
  4. Start writing Python code that loads best.pt and returns board coordinates.

If Results Are Bad

Classify the failure first. Do not guess.

No box:
  lower confidence and check if weak boxes exist

Many boxes:
  train longer, add cleaner labels, or raise confidence

Wrong area:
  add more examples where that wrong area appears

Box includes bench:
  make labels more consistent and relabel edge cases

Works on train, fails on new images:
  add varied data and use real validation

The Iteration Loop

predict many images
find failure pattern
fix labels or add examples
retrain
predict again

Most Important Rule

Do not add random data. Add data that represents the failures you actually see.
