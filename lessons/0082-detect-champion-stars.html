Detect Champion Stars

Your board-state result is good enough to add the next field: star_level. Do this as a small classifier on champion crops first.

Win for this lesson: choose the first star-detection design without making the pipeline too complicated.

The Correct First Design

Start with classification, not detection. You already have a champion box. Use that box to crop one champion, then classify the crop as one of four classes: 

data/champion-star/
  labeled/
    1star/
    2star/
    3star/
    unknown/

Use unknown for bad boxes, UI pieces, unclear crops, or champions where the star signal is not visible.

Step 1: Make Star Crops

Reuse the current champion detector. For every board crop, detect champion boxes and save one crop per box. Use more top padding than champion identity, because star information is often near the top area around the champion health/name UI. 

outputs/champion-star-crops/
  image_388_box_000.png
  image_388_box_001.png
  image_389_box_000.png

Step 2: Label The Crops

Look at each crop by hand first. Move it into exactly one folder: 

1star    -> visible one-star champion
2star    -> visible two-star champion
3star    -> visible three-star champion
unknown  -> unclear or bad crop

Step 3: Split Train And Val

The folder layout should match the same Ultralytics classification format you used for champion identity: 

data/champion-star/
  train/
    1star/
    2star/
    3star/
    unknown/
  val/
    1star/
    2star/
    3star/
    unknown/

Step 4: Train A Star Classifier

Use a classifier because each crop should return one label. 

yolo classify train \
  model=yolo11n-cls.pt \
  data=data/champion-star \
  imgsz=160 \
  epochs=50 \
  device=mps \
  project=../runs/classify \
  name=champion-star

Step 5: Connect Back To Board State

Add the star classifier beside champion identity in Champion-to-Hex Evidence: 

champion box
  -> identity crop -> champion_name
  -> star crop     -> star_level
  -> chosen hex    -> Board State JSON

The Board State unit should become: 

{
  "row": 2,
  "column": 0,
  "champion": "warwick",
  "star_level": 2,
  "star_confidence": 0.91
}

Important Rule

Do not mix star labels into champion identity. warwick and 2star are two different questions, so they should be two different classifiers.

Retrieval Check

A. Train one classifier with champion names and stars mixed together.
B. Train a small star classifier on champion crops.
C. Train a new board detector for stars.

Answer: B. Star level is a separate visual attribute of a detected champion.
