After Predicting Champion Boxes

After the champion detector predicts boxes on board crops, your next job is not to train names from the board image. Your next job is to turn each good box into one labeled champion crop.

Win for this lesson: know the exact order from predicted boxes to champion-name model.

One Rule

A detector answers where is a champion?. A classifier answers which champion is this crop?. Keep those as two separate models.

Step 1: Review The Prediction Images

Open the predicted images and quickly check whether the boxes are good enough. Your latest review output is: 

/Users/inmac/Desktop/work-hard/tft-team-strength/runs/detect/outputs/review/champion-detector-current-all-2

If boxes are mostly correct, continue. If many champions are missed, label more detector boxes first and retrain models/champion-detector.pt.

Step 2: Label New Champion Names

Use the identity labeler on the YOLO export that contains your champion boxes. For your new images, use the image range you added: 

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

python3 scripts/label_champion_identity.py \
  --export exports/label-studio/champion-111.zip \
  --start-image-index 388 \
  --end-image-index 404

In the browser, click each box and choose the champion name. The tool saves one crop into: 

data/champion-identity/labeled/<champion_name>/

Step 3: Fix Obvious Folder Mistakes

Before splitting, folder names are labels. A typo becomes a new wrong class. Check for names like orn, tristina, pe, or empty folders. 

find data/champion-identity/labeled -mindepth 1 -maxdepth 1 -type d | sort

Step 4: Split Train And Val

This creates the Ultralytics classification layout: train/name/*.png and val/name/*.png. Ultralytics documents this folder-per-class structure for classification datasets. 

python3 scripts/split_champion_identity_dataset.py

Step 5: Train Champion Identity

Start with a small classifier image size because each input is only a champion crop. 

yolo classify train \
  model=yolo11n-cls.pt \
  data=data/champion-identity \
  imgsz=96 \
  epochs=50 \
  device=mps

Step 6: Test On One Board

After training, the code path should become: 

board crop
  -> champion box detector
  -> choose one hex for each box
  -> crop the champion box
  -> champion-name classifier
  -> result: hex + champion name

Retrieval Check

A. Train champion names from full board crops.
B. Label each detected champion crop, then train a classifier.
C. Detect star level before champion name.

Answer: B. The name model needs one cropped champion image as input, not the whole board.
