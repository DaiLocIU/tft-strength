Test The Champion Detector Pilot

After training, do not label more yet. First, look at prediction images and decide whether the champion detector is useful enough to combine with hex occupancy.

Goal: check whether models/champion-detector.pt detects real champions and ignores little legends, health bars, item effects, and background noise.

Do This Now

  1. Run prediction on the validation images.
  2. Open the saved prediction images.
  3. Count only the important mistakes.
  4. Decide whether the detector is ready for box-to-hex mapping.

Command

Run this from the vision project folder:

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

.venv/bin/yolo detect predict \
  model=models/champion-detector.pt \
  source=data/champion-detector/images/val \
  imgsz=640 \
  conf=0.25 \
  save=True \
  project=outputs/champion-detector \
  name=pilot-val

Where To Look

/Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector/outputs/champion-detector/pilot-val

What To Check

For each saved prediction image, write a short note like this:

image_371:
  missed Kayle body
  false box on little legend

image_383:
  found Blue
  missed Ivern
  no false little legend box

Decision Rule

good enough:
  most champion bodies are detected
  little legends are usually ignored
  boxes are near the champion body

not ready:
  many champions are missed
  little legends are detected as champions
  boxes mostly hit health bars or item icons

Why This Step Matters

The champion detector does not need to solve the final hex position yet. This test only asks: is there useful champion evidence in the image? If yes, the next coding step is to draw champion boxes and hex centers together, then test simple mapping rules.
