Handle Zero, One, Or Many Detections

Production inference code must handle more than the happy path.

The Three Cases

0 boxes  -> return None
1 box    -> return that box
2+ boxes -> choose highest confidence

Why Highest Confidence?

Your board detector should return one board. If it returns more than one, the first practical rule is to trust the box the model scores highest.

best_index = int(boxes.conf.argmax())

argmax means: give me the index of the largest value.

Typed Boundary

Ultralytics works at runtime, but its Python types are broad. Keep that looseness near the library call:

results = cast(list[Any], model(image_path))

Then return your own strict app shape:

BoardDetection | None

Mental Model

external library output: flexible, messy
your app output: small, typed, predictable
