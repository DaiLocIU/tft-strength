Create The Second Hex Row

After the bottom row looks acceptable, the next step is one row above it. Do not build all 28 cells yet. Add only the second row so you can inspect one new idea: row offset.

Goal: calculate seven hexes in row 2 from the bottom-row geometry.

The New Idea

A pointy-top hex row above another row is not directly above it like a square grid. It is shifted sideways by half of the center-to-center step. 

second_row_x = bottom_start_x + center_step / 2 + column * center_step
second_row_y = bottom_center_y - vertical_step

For a regular pointy-top hex, the vertical center step is roughly 1.5 * radius. This is a starting point for visual tuning, not a promise that every TFT crop has perfect geometry.

Write One Helper

Add this after create_bottom_row_hex_cells:

def create_second_row_hex_cells(
    image_path: str,
    width_percent: float,
    height_percent: float,
    radius_percent: float,
    gap_percent: float,
) -> list[HexCell]:
    image = Image.open(image_path)
    width = image.width
    height = image.height

    bottom_start_x = width * (width_percent / 100)
    bottom_center_y = height * (height_percent / 100)
    radius = width * (radius_percent / 100)
    border_gap = width * (gap_percent / 100)
    hex_width = 2 * radius * cos(pi / 6)
    center_step = hex_width + border_gap
    vertical_step = 1.5 * radius

    hexes: list[HexCell] = []

    for column in range(7):
        hexes.append(
            {
                "row": 2,
                "column": column,
                "center_x": bottom_start_x + center_step / 2 + column * center_step,
                "center_y": bottom_center_y - vertical_step,
                "radius": radius,
            }
        )

    return hexes

Draw Two Rows

In __main__, create both rows and draw them together. Keep the bottom row so you can compare the offset. 

bottom_row = create_bottom_row_hex_cells(
    crop_path,
    tuning["width_percent"],
    tuning["height_percent"],
    tuning["radius_percent"],
