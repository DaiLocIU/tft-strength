Write The First Champion To Hex Script

You now have board crops, hex centers, and a champion detector that is good enough for normal cases. The next step is to write one small visual script that maps detected champion boxes to hexes.

Win for this lesson: create one review image where every detected champion box points to a selected row,column hex.

Step 1: Create The Script

Create this file:

vision-board-detector/scripts/map_champions_to_hexes.py

Start with one board crop. Do not batch all images yet.

IMAGE_NAME = "image_1.png"
MODEL_PATH = "models/champion-detector.pt"
CROPS_DIR = "outputs/board-crops"
OUTPUT_DIR = "outputs/champion-hex-map"

Step 2: Reuse Your Hex Code

Import create_board_hex_cells from detect_hexes.py. Do not rewrite the hex geometry. 

from detect_hexes import HexCell, HexTuning, create_board_hex_cells

Step 3: Run The Champion Detector

Load models/champion-detector.pt and run prediction on one board crop. 

model = YOLO(MODEL_PATH)
results = model(image_path, conf=0.5, verbose=False)

Step 4: Convert Box To Point

Each champion box becomes one point. Use the bottom-center of the box because it is closest to the champion's board position. 

point_x = (x1 + x2) / 2
point_y = y2

Step 5: Choose The Nearest Hex

Compare the bottom-center point to all 28 hex centers. The closest one is the first mapping guess. 

distance = (point_x - hex_x) ** 2 + (point_y - hex_y) ** 2

Step 6: Draw A Review Overlay

The output image should show four things at the same time.

green rectangle:
  champion detector box

yellow dot:
  bottom-center point

red hex:
  selected nearest hex

white text:
  row,column

Step 7: Run It

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

.venv/bin/python scripts/map_champions_to_hexes.py image_1.png

Step 8: Review The Output

open outputs/champion-hex-map

Decision

if selected hexes match champion positions:
  run the script on more board crops

if selected hexes are one row too low:
  move point_y upward a little

if selected hexes are one row too high:
  move point_y downward a little

if champion boxes are missing:
  collect those overlap images for later training
