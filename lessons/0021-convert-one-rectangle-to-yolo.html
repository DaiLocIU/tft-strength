The Two Formats

Label Studio rectangle:

x, y, width, height

x and y are the top-left corner. Values are percentages from 0 to 100.

YOLO rectangle:

class_id center_x center_y width height

center_x, center_y, width, and height are normalized values from 0 to 1.

The Formula

x = label_studio_x / 100
y = label_studio_y / 100
w = label_studio_width / 100
h = label_studio_height / 100

center_x = x + w / 2
center_y = y + h / 2
