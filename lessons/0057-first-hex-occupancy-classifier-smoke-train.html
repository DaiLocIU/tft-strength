First Hex Occupancy Classifier Smoke Train

Your hex occupancy dataset now has train and val folders. The next step is a tiny classifier training run, only to prove the pipeline works.

Goal: run a 1-epoch classification smoke train and confirm Ultralytics accepts the dataset.

Where You Are

Your dataset already has the folder shape Ultralytics classification expects:

data/hex-occupancy/
  train/
    occupied/ 641 images
    empty/    2019 images
  val/
    occupied/ 135 images
    empty/    537 images

In classification, the folder name is the label. So occupied and empty become the two classes.

Smoke Train Command

Run only 1 epoch first. This is not for a good model. It is for checking that the dataset loads, labels are found, and training produces output files. 

.venv/bin/yolo classify train \
  model=yolo11n-cls.pt \
  data=data/hex-occupancy \
  epochs=1 \
  imgsz=96 \
  project=runs/classify \
  name=hex-occupancy-smoke

Why classify?

Your board detector used object detection because it needed to find a rectangle. This model sees one already-cropped hex patch, so it only chooses a class. 

detect:
  image -> box positions

classify:
  image -> one label + confidence

What Success Looks Like

After the run, you should see a folder like this:

runs/classify/hex-occupancy-smoke/
  weights/
    best.pt
    last.pt
  results.csv
  results.png
  confusion_matrix.png

The important file is weights/best.pt. Later, that becomes your hex occupancy classifier.

Do Not Optimize Yet

Do not tune epochs, learning rate, or model size yet. First answer one question: can this dataset train end to end?

Stop Rule

After the 1-epoch run, ask Codex to inspect the result. We need these facts:

Did training finish?
Where is best.pt?
What were train/val classes?
What does the confusion matrix suggest?

Recall

  • Why is this a classification task?
  • Why run only 1 epoch first?
  • Which file becomes the trained classifier?
