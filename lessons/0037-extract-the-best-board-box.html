Extract The Best Board Box

Raw YOLO output is for inspection. App code needs one clean board detection.

Current Code

print(results[0].boxes)

This is useful while learning, but it is not the final interface.

Next Shape

class BoardDetection(TypedDict):
    x1: float
    y1: float
    x2: float
    y2: float
    confidence: float

Meaning

  • x1: left edge of the board box in pixels.
  • y1: top edge of the board box in pixels.
  • x2: right edge of the board box in pixels.
  • y2: bottom edge of the board box in pixels.
  • confidence: how sure YOLO is.

Function Goal

def detect_board(image_path: str) -> BoardDetection | None:
    ...

Return None when no board is detected.

Small Steps

  1. Get the first result: result = results[0].
  2. Get boxes: boxes = result.boxes.
  3. If there are no boxes, return None.
  4. Read the first box coordinates from boxes.xyxy.
  5. Read confidence from boxes.conf.

Why First Box?

Your board detector should usually return one high-confidence board box. For the first version, choosing the first box is enough. Later we can explicitly choose the highest-confidence box.
