Train The First Champion Name Model

You have enough champion boxes and labeled crops to move from detection to identity. The next model should classify one champion crop into one champion name.

Current state: you have labeled crops, but no train/ and val/ split yet. So the next command is the split command.

The Mental Model

champion-detector.pt
  input: board crop
  output: champion boxes

champion-identity-classifier.pt
  input: one champion crop
  output: champion name

Step 1: Check Label Folders

Folder names become class names. If a folder is a typo, the model learns a typo as a real champion. 

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

find data/champion-identity/labeled -mindepth 1 -maxdepth 1 -type d | sort

Fix obvious bad folders before training. Empty folders are okay, but typo folders are not.

Step 2: Split Labeled Crops

This creates the folder layout YOLO classification expects: data/champion-identity/train/name/*.png and data/champion-identity/val/name/*.png. 

python3 scripts/split_champion_identity_dataset.py

Step 3: Train The Classifier

Use classify train, not detect train. You are no longer training boxes here. 

yolo classify train \
  model=yolo11n-cls.pt \
  data=data/champion-identity \
  imgsz=96 \
  epochs=50 \
  device=mps \
  project=runs/classify \
  name=champion-identity

Step 4: Save The Best Model

After training, copy the best classifier into models/ so your scripts can use a stable path. 

cp runs/classify/champion-identity/weights/best.pt \
  models/champion-identity-classifier.pt

Step 5: Test One Crop First

Before connecting to hexes, test the classifier on one labeled crop. This checks whether the model can answer the small question. 

yolo classify predict \
  model=models/champion-identity-classifier.pt \
  source=data/champion-identity/val \
  imgsz=96

Step 6: Then Connect Back To Hex

Only after the classifier works, update your board pipeline: 

board crop
  -> detect champion boxes
  -> choose one hex per champion box
  -> crop that box
  -> classify champion name
  -> output: row, column, champion

Retrieval Check

A. detect train on champion names
B. classify train on champion crops
C. classify train on full boards

Answer: B. Champion names are learned from individual champion crops.
