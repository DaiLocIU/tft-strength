What The Python Scaffold Teaches

The generated code is not the lesson by itself. It is a small machine you can take apart.

Mission link: every file supports one question: how does a labeled screenshot become a model that can find the TFT board?

The Whole Loop

raw screenshot
  -> Label Studio rectangle
  -> Label Studio JSON export
  -> YOLO label text file
  -> YOLO training
  -> board prediction

What Each File Teaches

label_studio/board_label_config.xml teaches annotation design. You learn how to define the UI that a human uses to create ground truth.

board_detection/label_studio.py teaches how to read external tool data. Label Studio exports JSON, and this file extracts only the rectangles labeled board.

board_detection/yolo.py teaches coordinate conversion. This is the most important beginner concept here: Label Studio uses percentages from the top-left corner, while YOLO uses normalized center coordinates.

scripts/convert_label_studio_to_yolo.py teaches dataset preparation. Model training usually fails because the dataset is shaped wrong, not because the model is mysterious.

scripts/train_board_detector.py teaches transfer learning. You start from pretrained YOLO weights and fine-tune them on your one class: board. See the Ultralytics Python guide.

scripts/predict_board.py teaches inference. After training, you give the model an image and read back boxes, confidence scores, and coordinates.

The First Concept To Understand

Focus on this function first:

def label_studio_rect_to_yolo(rect):
    x = rect["x"] / 100
    y = rect["y"] / 100
    w = rect["width"] / 100
    h = rect["height"] / 100
    cx = x + w / 2
    cy = y + h / 2
    return cx, cy, w, h

If a board rectangle starts at x=10%, y=20%, and has width=50%, height=40%, then YOLO wants:

center_x = 10% + 50% / 2 = 35%
center_y = 20% + 40% / 2 = 40%
width    = 50%
height   = 40%

What You Are Learning

  • How annotation tools describe image regions.
  • How object detectors expect training labels.
  • Why coordinate systems matter in computer vision.
  • How a dataset pipeline connects human labels to model training.

Next Step

Do not train yet. First, label 3 screenshots and export JSON from Label Studio. Then inspect the JSON so you can recognize the fields: x, y, width, height, and rectanglelabels.

Ask the agent to quiz you on coordinate conversion before moving to training. That will build storage strength, not just fluency.
