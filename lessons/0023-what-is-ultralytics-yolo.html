What Is Ultralytics YOLO?

Ultralytics YOLO is the tool we will use to train and run your TFT board detector.

The Short Version

YOLO means You Only Look Once. It is a computer vision model style for finding objects in images.

Ultralytics is the Python package and command-line tool that makes YOLO practical to use.

For Your Project

Input:  TFT screenshot

Model:  Ultralytics YOLO detector

Output: one board box
        class = board
        confidence = how sure the model is
        x/y/w/h = where the board is

What Ultralytics Gives You

  • Train: learn from your labeled board images.
  • Predict: find the board in a new screenshot.
  • Val: measure if the model works on images it did not train on.
  • Export: convert the trained model for later app use.

Important Mental Model

You do not write the neural network from scratch.

You prepare the data correctly.
You call the trainer.
You inspect the result.
You improve the data.

Why We Use It Now

Your first learning goal is not to invent a detector algorithm. Your first goal is to understand the full computer vision loop:

images -> labels -> YOLO dataset -> train -> predict -> inspect mistakes
