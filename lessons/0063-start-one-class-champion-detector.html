Start One-Class Champion Detector

The next step is to train a detector that finds champion bodies on the board. Do not train champion names yet. First, train one class only: champion.

Goal: detect one champion body as one object, then later map its bottom-center point to the nearest hex.

The New Question

Your hex classifier asks whether one crop looks occupied. The champion detector asks where each full champion body is. 

hex classifier:
  input: one hex crop
  output: empty / occupied

champion detector:
  input: whole board crop
  output: boxes around champions

What To Label

Use board crop images, not tiny hex crop images. On each selected board crop, draw one box around each champion on your side of the board. 

one champion = one box
large champion = one big box
body covers 3 hexes = still one box
small champion = one small box

What Not To Label

The detector must learn champion bodies, not every bright or moving thing on the board. 

do not label:
  little legend
  item effect only
  shadow only
  empty hex
  enemy board if you are focusing player side

Pick Images

Start with 30 to 50 board crops. Pick hard images, but label all champions in each selected image. 

good first batch:
  Blue cases
  Nunu cases
  Kayle cases
  Ivern cases
  Elder Dragon cases
  Maokai cases
  normal champion cases too

Why Label All Champions?

If you label only the large champion, YOLO sees the normal champions as background. That teaches the wrong lesson. For any image you choose, label every visible player-side champion.

Later Code

After detection works, code will convert each box into one standing point. 

standing_x = box center x
standing_y = box bottom y

standing point
  -> nearest hex center
  -> occupied hex

Do This Now

  1. Create a new detection dataset called champion-detector.
  2. Use board crops from outputs/board-crops.
  3. Pick 30 to 50 hard board crops.
  4. Use one label class: champion.
  5. Draw one rectangle around every player-side champion body.
  6. Do not label little legends or item effects alone.

Recall

  • If Kayle covers three hexes, how many boxes do you draw?
  • Why should normal champions also be labeled in a hard image?
  • What point from the box will later map to the standing hex?
