Understand First YOLO Train Output

Your first YOLO run succeeded. Now read the output as a pipeline check, not as model quality.

The Most Important Result

runs/detect/train/weights/best.pt

This is the trained model file. It is what you use for prediction.

The Validation Line

Class  Images  Instances  Box(P)  R  mAP50  mAP50-95
all    100     100        ...     ... ...    ...
  • Images: how many validation images YOLO checked.
  • Instances: how many labeled objects it saw. You have 100 boards.
  • Box(P): precision. When YOLO predicts boxes, how often are they right?
  • R: recall. How many real boards did YOLO find?
  • mAP50: detection score using a looser box-overlap rule.
  • mAP50-95: stricter detection score across many overlap levels.

Do Not Trust The Metrics Yet

You trained for one epoch and temporarily used the same folder for train and validation. That is useful only to prove the files are readable.

Useful Files

  • weights/best.pt: best saved model.
  • weights/last.pt: model at the final epoch.
  • args.yaml: exact training settings used.
  • results.csv: metrics as numbers.
  • results.png: metrics as charts.
  • train_batch*.jpg: images plus training labels.
  • val_batch*_pred.jpg: validation images plus predictions.
