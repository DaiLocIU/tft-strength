Write One YOLO Label File

Now that one board rectangle can become one YOLO line, write that line into one matching .txt file.

The Rule

For every image file, YOLO expects one label file with the same base name.

image_1.png  -> image_1.txt
image_19.png -> image_19.txt

Your First Target

Do not build the full dataset exporter yet. First write one label file:

data/yolo/labels/train/image_1.txt

Inside it, the content should look like this:

0 0.493813 0.448680 0.489074 0.460411

The Function Boundary

image filename + YOLO line + output folder -> one .txt file

Function To Write

def write_yolo_label_file(
    image_filename: str,
    yolo_line: str,
    labels_dir: str,
) -> None:
    ...

Steps Inside The Function

  1. Convert labels_dir to a Path.
  2. Create the folder with mkdir.
  3. Change the image suffix from .png to .txt.
  4. Write the YOLO line plus a final newline.

Self Check

After running your script, this command should print one YOLO row:

cat data/yolo/labels/train/image_1.txt
