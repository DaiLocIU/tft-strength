CPU vs GPU And GPU Memory

A CPU is good at many different jobs. A GPU is good at doing many simple math jobs at the same time.

CPU

CPU = general-purpose worker

It is good for app logic, files, Python control flow, operating system work, and many different tasks.

GPU

GPU = parallel math worker

It is good for neural network training because training repeats huge amounts of matrix math.

Why Training Likes GPU

image pixels
-> tensors
-> matrix math
-> prediction
-> loss
-> gradients
-> weight update

Most of this is repeated numeric math, so GPU can be much faster.

Apple Silicon

On your Mac, PyTorch uses Apple's Metal Performance Shaders backend. In commands, this is:

device=mps

GPU_mem 4.27G

This means the training process is using about 4.27 GB of GPU-accessible memory.

GPU_mem 0G    -> not using GPU
GPU_mem 4.27G -> using GPU memory

What Uses That Memory?

  • model weights
  • image batches
  • intermediate tensor results
  • gradients used for learning
  • optimizer/training state

If GPU Memory Is Too High

Reduce one of these:

batch
imgsz
model size
