Draw One Hex Center On A Real Board

You are right: geometry is easier to fix when you can see it on the image. So before building all 28 hexes, draw one center point on a real cropped board.

Today’s goal: write one function that draws a red dot and label for one HexCell.

Why Draw So Early?

Printed numbers like center_x=100 do not tell you if the cell is correct on a TFT board. A review image gives a fast feedback loop: run code, open image, decide what is wrong.

Add Imports

from pathlib import Path

from PIL import Image, ImageDraw

Create One Real-Looking Cell

def create_first_hex_cell() -> HexCell:
    return {
        "row": 0,
        "column": 0,
        "center_x": 190.0,
        "center_y": 460.0,
        "radius": 45.0,
    }

These numbers are not final. They are only a starting guess on outputs/board-crops/image_1.png.

Draw The Center

def draw_hex_center(
    image_path: str,
    hex_cell: HexCell,
    output_path: str,
) -> None:
    image = Image.open(image_path).convert("RGB")
    draw = ImageDraw.Draw(image)

    center_x = hex_cell["center_x"]
    center_y = hex_cell["center_y"]
    label = f"{hex_cell['row']},{hex_cell['column']}"

    dot_radius = 8
    draw.ellipse(
        (
            center_x - dot_radius,
            center_y - dot_radius,
            center_x + dot_radius,
            center_y + dot_radius,
        ),
        fill="red",
    )
    draw.text((center_x + 10, center_y - 8), label, fill="white")

    review_path = Path(output_path)
    review_path.parent.mkdir(parents=True, exist_ok=True)
    image.save(review_path)

How To Judge It

  • If the dot is too far left, increase center_x.
  • If the dot is too far right, decrease center_x.
  • If the dot is too high, increase center_y.
  • If the dot is too low, decrease center_y.

Recall

  • Why is a dot easier than drawing the full hex first?
  • Which value moves the dot left or right?
  • Which value moves the dot up or down?
