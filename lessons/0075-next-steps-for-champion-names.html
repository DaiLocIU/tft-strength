Next Steps For Champion Names

Your champion detector is good enough to reuse. The next skill is turning each detected box into a labeled champion-name crop.

Win for this lesson: know the exact next workflow before writing the classifier code.

The Decision

Do not retrain the detector with every champion name yet. Keep the detector as champion. Add a second model: a classifier that receives one cropped champion image and returns kayle, nunu, or another name.

Step 1: Produce Champion Crops

board crop image
  -> current champion detector
  -> boxes
  -> crop each box
  -> save each crop for labeling

Step 2: Label Names By Folder

For classification, the folder name is the label. This is different from YOLO detection labels, where a text file stores box coordinates. 

data/champion-identity/labeled/
  kayle/
    crop_001.png
    crop_002.png
  nunu/
    crop_003.png
    crop_004.png
  unknown/
    crop_005.png

Step 3: Start Tiny

Pick only two champion names first, for example kayle and nunu. Add unknown for bad crops or champions you are not training yet.

Step 4: Split Train And Val

data/champion-identity/
  train/
    kayle/
    nunu/
    unknown/
  val/
    kayle/
    nunu/
    unknown/

Step 5: Train Classifier

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

yolo classify train \
  model=yolo11n-cls.pt \
  data=data/champion-identity \
  imgsz=96 \
  epochs=50

Step 6: Connect Back To Hex

champion box
  -> chosen hex from combine rule
  -> crop box
  -> classifier predicts name
  -> output: row=3 column=4 champion=nunu

Step 7: Stars Come Later

Star level should be a separate step after champion name works. First solve: which champion is on this hex?. Later solve: how many stars?.

Retrieval Check

A. Train one detector with kayle/nunu boxes immediately.
B. Reuse champion detector, crop boxes, train name classifier.
C. Detect star level before champion identity.

Answer: B. It reuses your good detector and gives the shortest path to champion names.
