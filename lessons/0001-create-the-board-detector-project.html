Create The Board Detector Project

Your first computer vision win is small and concrete: teach a model to find the TFT board as one object.

Mission link: We are not detecting champions yet. We are building the cropper that finds the board area first.

What You Built

The folder vision-board-detector/ is a clean Python project with four jobs:

  • store raw TFT screenshots,
  • define the Label Studio labeling UI,
  • convert Label Studio exports to YOLO format,
  • train and run a one-class YOLO detector.

The Mental Model

An object detector learns from many examples of this form:

image + rectangle around object + class name

For this project, the class name is always board. Label Studio stores rectangle positions as percentages of image size in its JSON export, and the converter script turns those percentages into the normalized YOLO label format. See the Label Studio export guide.

Step 1: Put Screenshots In Raw Data

mkdir -p vision-board-detector/data/raw

Copy 10 to 30 full TFT screenshots into that folder. Use original screenshots, not cropped boards.

Step 2: Label In Label Studio

Create a Label Studio project and use this config:

vision-board-detector/label_studio/board_label_config.xml

Draw one rectangle around only the playable board region. The official Label Studio docs describe exporting annotations when your first batch is labeled.

Step 3: Convert To YOLO

cd vision-board-detector
python scripts/convert_label_studio_to_yolo.py \
  --export exports/label-studio/board-export.json \
  --images data/raw \
  --out datasets/tft-board-yolo

Step 4: Train

Ultralytics provides a Python API for loading a pretrained YOLO model and training it on a custom detection dataset. See the Ultralytics Python usage guide.

python scripts/train_board_detector.py \
  --data datasets/tft-board-yolo/dataset.yaml \
  --epochs 30

Step 5: Predict

python scripts/predict_board.py \
  --weights runs/detect/tft-board/weights/best.pt \
  --source data/raw/example.png
