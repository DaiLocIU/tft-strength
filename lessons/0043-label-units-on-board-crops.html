Label Units On Board Crops

The board detector gives you a clean board image. The next detector should find units on that board.

Next target: one class named unit. Do not label champion names yet.

Why Not Champion Names Yet?

Champion identity is harder than unit location. A champion can have skins, items, effects, size changes, and overlap. First learn the simpler task: draw a box around every unit on the cropped board.

After the model can find units reliably, you can crop each unit and build a separate classifier for champion identity.

Copy only good board crops into data/unit-raw. Start small: 30 to 50 images is enough for the first smoke test.

Label Studio Config

Use the same object-detection style as before. Label Studio's RectangleLabels creates bounding boxes on images, and its result stores x, y, width, and height as percentages of the image. Source: Label Studio RectangleLabels docs. 

<View>
  <Image name="image" value="$image"/>
  <RectangleLabels name="label" toName="image">
    <Label value="unit" background="#00AAFF"/>
  </RectangleLabels>
</View>

Labeling Rule

  • Draw one rectangle around each visible unit on the board.
  • Do not label bench units.
  • Do not label shop cards.
  • Do not label the Little Legend unless you want it as a separate class later.
  • Keep boxes consistent; perfect edges are less important than repeatable rules.

What This Unlocks

A board detector finds the play area. A unit detector finds every unit inside that play area. Together, they create small unit crops that later become input for champion recognition.
