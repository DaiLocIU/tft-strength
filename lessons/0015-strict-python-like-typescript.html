Strict Python Like TypeScript

Python can feel closer to TypeScript if you use type hints, a type checker, and a linter.

The Difference

TypeScript checks types before runtime. Python normally waits until runtime. Strict Python adds a separate checker so many mistakes are caught earlier.

The Three Tools

  • type hints: annotations you write in Python code.
  • mypy or pyright: static type checkers.
  • ruff: fast linting and style checks.

Example

def clean_filename(name: str) -> str:
    return name.strip()

This tells the checker: name must be a string, and the function returns a string.

Commands

cd vision-board-detector
.venv/bin/python -m pip install mypy ruff
.venv/bin/python -m mypy scripts/check_dataset.py
.venv/bin/python -m ruff check scripts/check_dataset.py

Important

Your venv currently uses Python 3.9.6, so the strict config targets Python 3.9 syntax. That means avoid newer syntax like list[str] until we intentionally move the venv to a newer Python.

The goal is not perfect typing immediately. The goal is to make one function clearer and easier to trust.
