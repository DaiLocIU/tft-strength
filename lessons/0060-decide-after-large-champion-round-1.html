Why Threshold Now?

Your current code accepts occupied at 0.50. That is permissive. For a board overlay, a false red hex is very visible, so you may prefer fewer false positives. 

current:
  occupied if confidence >= 0.50

possible next test:
  occupied if confidence >= 0.75

The Tradeoff

A higher threshold can remove wrong red hexes, but it may also miss real champions that the model sees with lower confidence. 

higher threshold:
  fewer false occupied hexes
  more possible missed champions

Stop Rule

Do not train again until you know whether the wrong red hexes are low-confidence or high-confidence. That tells you which fix to use. 

low confidence wrong red hexes:
  change threshold first

high confidence wrong red hexes:
  label more edge cases

Recall

  • Which error creates wrong red hexes?
  • Why might 0.50 be too low?
  • When should you label more instead of changing threshold?
