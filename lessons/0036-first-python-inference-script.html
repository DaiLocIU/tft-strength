First Python Inference Script

The trained model is now stable. The next step is using it from Python code.

Current State

models/board-detector.pt

This file is your board detector. The app should load this path, not a temporary runs/... training path.

Goal

input: image path
output: board box coordinates + confidence

New Script

scripts/predict_board.py

First Version Should Only Do This

  1. Load models/board-detector.pt.
  2. Run prediction on one screenshot.
  3. Print each detected box.
  4. Print confidence.

Why This Matters

The CLI is good for experiments. Python inference code is what your real app will call.

training command -> creates model
inference code   -> uses model in product
