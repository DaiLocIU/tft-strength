Use The Hex Classifier On One Board

The classifier smoke train worked. The next step is to connect it back to the TFT board pipeline and predict occupied hexes on one board crop.

Goal: load best.pt, classify every hex patch on one board crop, and draw the predicted occupied hexes.

What The Smoke Result Means

The 1-epoch validation result was already useful:

true empty predicted empty:       527
true empty predicted occupied:    10
true occupied predicted empty:    10
true occupied predicted occupied: 125

That is 652 / 672 = 97.0% correct on the validation split. This is good enough to test the full pipeline on real board crops.

The New Pipeline Step

Before, you only trained the classifier. Now you need to use it. The classifier should run once for each generated hex patch. 

board crop
  -> create 28 hex cells
  -> crop one patch per hex
  -> classifier predicts empty / occupied
  -> draw occupied hexes on board crop

Model File

The trained classifier is here:

runs/classify/runs/classify/hex-occupancy-smoke/weights/best.pt

For the next script, copy or reference this file as the hex occupancy model. Do not replace models/board-detector.pt; that model still detects the board rectangle.

Small Script Shape

The next script should stay small:

scripts/predict_hex_occupancy.py

load classifier model
load one board crop
create hex cells
crop each hex patch
predict occupied / empty
draw occupied hexes
save review image

Expected Output

The first version should print rows and columns, then save one visual review image.

occupied: row=0 column=3 confidence=0.98
occupied: row=1 column=1 confidence=0.94
saved: outputs/hex-occupancy/image_1-predicted.png

Stop Rule

Stop after one board crop. If the visual overlay looks mostly right, then run it on many board crops and make a prediction contact sheet. If it looks wrong, inspect the crop size, labels, and confidence threshold before training longer.
