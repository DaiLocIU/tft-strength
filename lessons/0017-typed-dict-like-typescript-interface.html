TypedDict Like TypeScript Interface

For JSON data, Python's closest match to a TypeScript interface is TypedDict.

TypeScript Shape

interface TaskItem {
  data: {
    image: string;
  };
  annotations: AnnotationItem[];
}

const tasks: TaskItem[] = JSON.parse(text);

Python Shape

from typing import Any, List, TypedDict, cast

class TaskData(TypedDict):
    image: str

class RectangleValue(TypedDict):
    x: float
    y: float
    width: float
    height: float
    rectanglelabels: List[str]

class AnnotationResult(TypedDict):
    type: str
    value: RectangleValue

class AnnotationItem(TypedDict):
    result: List[AnnotationResult]

class TaskItem(TypedDict):
    data: TaskData
    annotations: List[AnnotationItem]

Typing json.load

json.load(file) returns Any, because Python cannot know what is inside a JSON file. You tell the type checker what shape you expect with cast:

raw_tasks = json.load(file)
tasks = cast(List[TaskItem], raw_tasks)

Important Warning

cast does not validate data at runtime. It is a promise to the type checker. Later, when you need real runtime validation, use Pydantic or manual checks.
