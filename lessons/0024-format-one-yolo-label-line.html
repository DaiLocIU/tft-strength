The Function Boundary

This function should not know about Label Studio. It only knows how to turn one YoloRectangle into one string.

YoloRectangle -> str

Function To Write

def yolo_rectangle_to_line(rectangle: YoloRectangle) -> str:
    ...

Rules

  • The values must be separated by spaces.
  • The class id should be first.
  • The four numbers should use a stable number of decimals.
  • The return value should be a string, not a printed value.

Self Check

line = yolo_rectangle_to_line(yolo_rectangle)
print(line)

If it prints one row like the YOLO file shape above, the function is doing its job.
