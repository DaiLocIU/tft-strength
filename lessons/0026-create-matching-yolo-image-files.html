Create Matching YOLO Image Files

YOLO labels are not enough. Every label file needs a matching image file.

What You Have Now

data/yolo/labels/train/image_1.txt
data/yolo/labels/train/image_2.txt
...

What YOLO Also Needs

data/yolo/images/train/image_1.png
data/yolo/images/train/image_2.png
...

The Matching Rule

images/train/image_1.png
labels/train/image_1.txt

The folder names are different, but the base filename must match.

Next Function

def copy_yolo_image_file(
    image_filename: str,
    raw_dir: str,
    images_dir: str,
) -> None:
    ...

Steps Inside

  1. Convert raw_dir and images_dir to Path.
  2. Create images_dir if missing.
  3. Build the source path from raw_dir / image_filename.
  4. Build the destination path from images_dir / image_filename.
  5. Copy the file.

New Standard Library Tool

from shutil import copy2

copy2(source, destination) copies the image and keeps useful file metadata.
