Verify Labels Match Images

Before converting labels, prove that every Label Studio task can find its image on disk.

Your current check passed: 100 labeled tasks, 100 matched images, 0 missing images.

The Problem

Label Studio stores image paths like this:

/data/upload/1/0992a392-image_2.png

Your local folder stores the original file:

vision-board-detector/data/raw/image_2.png

The Skill

You need to strip the Label Studio prefix and recover the original image name:

0992a392-image_2.png -> image_2.png

Your First Python File

Create this file yourself:

vision-board-detector/scripts/check_dataset.py

Write it in four tiny steps:

  1. Import json, re, and Path.
  2. Open exports/label-studio/board-100.json.
  3. For each task, read task["data"]["image"].
  4. Print the internal filename and recovered original filename.

Do Not Solve Everything

This first script should not convert to YOLO. It should only answer one question:

Can every label find its image?

Expected Output Shape

0992a392-image_2.png -> image_2.png
e17fad87-image_1.png -> image_1.png
...
matched: 100
missing: 0

Retrieval Check

  1. Which JSON field contains the Label Studio image path?
  2. Why do we strip the 8-character hash?
  3. Why verify image matching before YOLO conversion?

After you write check_dataset.py, ask the agent to review it. The goal is to learn the file matching step, not to rush to training.
