Fix The YOLO Images Folder

Your code generated labels correctly, but copied images into the labels folder.

The Bug

images_dir: str = "data/yolo/labels/train"

That default points to the label folder. It should point to the image folder.

The Fix

images_dir: str = "data/yolo/images/train"

Correct YOLO Shape

data/yolo/images/train/image_1.png
data/yolo/labels/train/image_1.txt

Why This Matters

YOLO does not scan one folder and guess which files are labels. It expects images and labels to live in predictable parallel folders.

After Fixing

Clean the accidentally copied PNG files from the labels folder, then run the exporter again.

find data/yolo/labels/train -name "*.png" | wc -l
find data/yolo/images/train -name "*.png" | wc -l
find data/yolo/labels/train -name "*.txt" | wc -l

The expected result is:

labels/train PNG files: 0
images/train PNG files: 100
labels/train TXT files: 100
