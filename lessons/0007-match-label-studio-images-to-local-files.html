Match Label Studio Images To Local Files

Before conversion or training, you need to know which JSON task belongs to which image file.

Your Export

Your first task points to this image path:

/data/upload/1/0992a392-image_2.png

This is Label Studio's internal upload path. The useful original filename is:

image_2.png

The Pattern

Label Studio added an 8-character hash before the original filename:

0992a392-image_2.png
^^^^^^^^ hash added by Label Studio
         image_2.png is your original name

Where Images Should Live

Put your original screenshots here:

vision-board-detector/data/raw/

If You Do Not Have The Original Images

Export a format that includes images, such as COCO with Images, then copy the downloaded images into vision-board-detector/data/raw/. But if you still have your original 279 screenshots, use those instead.
