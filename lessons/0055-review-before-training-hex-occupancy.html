Review Before Training Hex Occupancy

You now have enough labeled hex crops to begin model work. The next step is not training immediately. First, check whether the saved examples teach the right rule.

Current dataset: 776 occupied crops and 2556 empty crops.

The Rule

A classifier learns from examples. If the occupied folder contains many empty cells, the model learns confusion. If the empty folder contains many champions, the model learns the wrong boundary. 

good label:
  occupied image -> champion visible
  empty image    -> no champion visible

bad label:
  occupied image -> empty board
  empty image    -> champion body or feet

Do This Next

  1. Create a contact sheet for occupied patches.
  2. Create a contact sheet for empty patches.
  3. Scan both sheets with your eyes.
  4. Fix obvious wrong images by moving or deleting them.
  5. Only then split the data into train and val.

What To Look For

In occupied, most crops should contain a champion body, feet, weapon, or clear unit visual. In empty, most crops should contain only board texture. 

maybe okay:
  small champion edge
  spell effect near champion
  partial body but clear unit presence

probably wrong:
  pure board texture in occupied
  champion standing in empty
  crop mostly outside the board
  crop mostly UI instead of hex

After Review

The classifier dataset should use the Ultralytics classification folder layout. Folder names are labels, so occupied and empty must exist under both train and val. 

data/hex-occupancy/
  train/
    occupied/
    empty/
  val/
    occupied/
    empty/

Stop Rule

Ask Codex to train only after these are true:

contact sheets reviewed
bad labels fixed
train/val split created
both classes exist in train and val

Recall

  • Why review before training?
  • What does the folder name mean in a classification dataset?
  • Why does val need both occupied and empty?
