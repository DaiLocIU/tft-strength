Do Not Change Variable Types

Strict Python becomes easier when one variable name keeps one type.

The Problem

def verify_labels_match_images(export_path: str, raw_dir: str) -> VerifyResult:
    export_path = Path(export_path)
    raw_dir = Path(raw_dir)

export_path starts as a str. Then the code assigns a Path to the same name. Mypy rejects that.

The Fix

def verify_labels_match_images(export_path: str, raw_dir: str) -> VerifyResult:
    export_file = Path(export_path)
    raw_path = Path(raw_dir)

Now each name has one type:

export_path: str
export_file: Path
raw_dir: str
raw_path: Path

TypeScript Comparison

function verify(exportPath: string) {
  const exportFile = new Path(exportPath)
}

You would not usually reuse exportPath for a different type in TypeScript. Use the same habit in Python.

Second Problem

If your function says it returns VerifyResult, return a dictionary with named fields, not a tuple.

return {
    "matched": matched,
    "missing": missing,
    "valid_labels": valid_labels,
    "bad_labels": bad_labels,
}
