Balance Missed Champions And Wrong Names

Your names are mostly wrong only below about 70% identity confidence. But --champion-conf 0.65 misses real champions. The next skill is separating detector recall from identity trust.

Win for this lesson: use a lower detector threshold to find champions, and a higher identity threshold to decide whether to trust the name.

Two Thresholds

champion-conf
  controls: keep or drop detected champion boxes
  too high: misses real champions

identity-conf
  controls: trust or hide champion names
  too low: shows wrong names

The Next Decision

Since --champion-conf 0.65 misses champions, do not keep raising it. Lower it back toward recall, then hide weak names separately. 

recommended detector threshold: 0.45 or 0.50
recommended identity threshold: 0.70 or 0.75

Step 1: Run A Recall Test

Compare the same boards with two detector thresholds:

  --champion-conf 0.65 \
  --identity-padding 0.08

If 0.50 finds the missing champion and only adds a few extra boxes, prefer 0.50.

Step 2: Add Identity Gate

The board should not display weak names as if they are facts. Add an identity threshold: 

identity_confidence >= 0.70 -> draw champion name
identity_confidence <  0.70 -> draw unknown / ?

This lets the detector keep recall without letting the classifier create wrong names.

Step 3: Split Errors By Type

real champion missing completely
  -> detector data problem
  -> label more champion boxes, retrain champion-detector.pt

box is present but name is wrong or weak
  -> identity data problem
  -> save crop to correct labeled folder, retrain classifier

Step 4: Stop Criteria

Stop improving identity when wrong names mostly happen below your identity threshold. Then the product behavior is: 

good box + confident name -> champion name
good box + weak name      -> unknown
missing box              -> improve detector

Retrieval Check

A. Raise champion-conf until names look clean.
B. Lower champion-conf for recall, gate weak names separately.
C. Add more identity labels for missing detector boxes.

Answer: B. Missing boxes are detector recall; weak names are identity confidence.
