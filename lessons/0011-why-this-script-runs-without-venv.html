Why This Script Runs Without Venv

A Python script can run without a virtual environment if it only uses modules that come with Python.

Your Current Imports

import json
import re
from pathlib import Path

These are standard-library modules. That means Python already includes them. You do not need to install anything for this first dataset check.

When Venv Becomes Necessary

You need a virtual environment when your script imports third-party packages:

import cv2
from ultralytics import YOLO
from PIL import Image

Those packages do not come with Python. A venv gives this project its own installed dependencies without mixing them into your whole machine.

Rule For This Project

  • check_dataset.py: no venv required.
  • YOLO training script: venv required.
  • OpenCV image script: venv required.
