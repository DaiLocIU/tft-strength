Build A Missed Champion Labeling Batch

Your champion detector is missing many champions on board crops. The next step is not hex mapping yet. The next step is to collect the failures, label them, and retrain on better examples.

Win for this lesson: create a small, high-value labeling batch from images where the model already failed.

The Rule

More epochs repeat the same lesson. More labeled failure cases teach the model what it does not know yet.

Step 1: Keep The Failed Board Crops

Open your conf=0.5 prediction output and find board crops where real champions were missed. 

open outputs/champion-detector/clean-100-board-crops-conf050

Step 2: Choose The Next Batch

Pick about 50 board crops. Do not choose random easy images.

include:
  champions the model missed
  small champions
  dark champions
  bright spell effects
  overlapping champions
  champions near board edge
  little legend near board
  different board skins

Step 3: Label Every Champion

In each selected board crop, label every visible champion body. Use one class: champion.

Step 4: Rebuild The YOLO Dataset

After exporting from Label Studio, run your champion dataset preparation script again. 

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

.venv/bin/python scripts/prepare_champion_detector_dataset.py

Step 5: Check Before Training

Before training, quickly verify that images and label files match. If this fails, training will waste time. 

.venv/bin/python scripts/check_dataset.py data/champion-detector

Step 6: Retrain

Retrain only after the new labels are in the dataset and the dataset check passes.

.venv/bin/yolo detect train \
  model=models/champion-detector.pt \
  data=data/champion-detector/data.yaml \
  imgsz=640 \
  epochs=100 \
  name=champion-detector-more-missed-cases

Stop Condition

stop labeling when:
  most real champions are boxed at conf=0.5
  wrong boxes are rare
  missed champions are mostly unusual cases
