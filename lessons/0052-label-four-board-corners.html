Label Four Board Corners

You found the important mistake: a rectangle is not the playable board. The next step is to label the four trapezoid corners so a pose model can learn them.

Goal: create a small Label Studio project for one board object with four ordered keypoints.

Do This Next

Use your existing rectangle detector to create rough board crops first. Then label four playable-board corners on those crops. Crops are easier than full screenshots because the model no longer has to search the whole UI.

Corner Order

Use this order every time. Do not change it between images.

0 top_left
1 top_right
2 bottom_right
3 bottom_left

Label Studio Config

Use one rectangle label as the parent object and four keypoint labels as its corners. Label Studio's YOLO keypoint export expects ordered model_index values. 

<View>
  <Image name="image" value="$image" zoom="true" zoomControl="true" />

  <RectangleLabels name="bbox" toName="image">
    <Label value="board" background="#0f766e" />
  </RectangleLabels>

  <KeyPointLabels name="corners" toName="image" choice="multiple">
    <Label value="top_left" model_index="0" background="#dc2626" />
    <Label value="top_right" model_index="1" background="#2563eb" />
    <Label value="bottom_right" model_index="2" background="#16a34a" />
    <Label value="bottom_left" model_index="3" background="#ca8a04" />
  </KeyPointLabels>
</View>

Important Labeling Rule

After placing the four keypoints, attach them to the board rectangle in the Regions panel. The rectangle is the object; the keypoints describe that object.

Dataset Shape

Create a new dataset folder. Do not mix this with your old rectangle detector dataset.

data/board-corners-yolo/
  images/train/
  images/val/
  labels/train/
  labels/val/
  dataset.yaml

The YOLO pose label line will eventually look like this:

0 box_cx box_cy box_w box_h tl_x tl_y tr_x tr_y br_x br_y bl_x bl_y

Small Batch

Start with 20 images: 16 train and 4 validation. Choose different maps, resolutions, and video qualities. The goal is to prove the labeling and conversion loop before labeling 100.
