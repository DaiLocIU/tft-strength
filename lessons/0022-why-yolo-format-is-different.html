Why YOLO Format Is Different

Label Studio and YOLO describe the same rectangle with different coordinate conventions.

Label Studio Format

Label Studio rectangle labels use top-left coordinates plus size:

x y width height

Meaning:

x: left edge
y: top edge
width: box width
height: box height

YOLO Format

YOLO detection labels use one text file per image. Each row is one object:

class_id center_x center_y width height

For your board detector, class_id is always 0, because board is the only class.

The Main Difference

Label Studio: top-left x/y
YOLO:         center x/y

Example:

Label Studio:
x=10, y=20, width=50, height=40

YOLO:
center_x = 10 + 50 / 2 = 35
center_y = 20 + 40 / 2 = 40

Why Not Train With Normal x/y?

You can train with top-left x/y if you write your own training code or use a tool that expects that format. But Ultralytics YOLO expects its own label files. If you give it Label Studio JSON directly, it will not know how to read it.

Why Normalize 0 To 1?

Normalized coordinates make labels independent of image resolution. A board in a 1920px image and a board in a 3456px image can share the same relative location.

Mental Model

Label Studio JSON is for humans and annotation tools.
YOLO TXT is for the YOLO training program.
