Split Hex Occupancy Into Train And Val

After reviewing the contact sheets, the next real step is to create a training set and a validation set for the classifier.

Goal: turn data/hex-occupancy/labeled into an Ultralytics classification dataset with train and val folders.

Why Split?

The classifier needs two groups. train teaches the model. val tests whether the model works on examples it did not train on. 

train:
  examples the model learns from

val:
  examples held back for checking

The Important Rule

Split by original board image, not by random patch. Patches from the same board are visually related. If some patches from image_120 go to train and other patches from image_120 go to val, the validation result becomes too easy. 

good:
  image_120_* all in train
  image_121_* all in val

bad:
  image_120_r0_c0 in train
  image_120_r0_c1 in val

Target Folder Shape

Ultralytics classification uses folder names as labels. That means both occupied and empty must exist under both train and val. 

data/hex-occupancy/
  train/
    occupied/
    empty/
  val/
    occupied/
    empty/

Split Size

Use about 80% of board images for training and 20% for validation. With your current dataset, that is a good first split. Later, you can improve it by making sure different maps and video sources appear in both groups.

Your Next Command

After you finish scanning the contact sheets, ask Codex to implement this script:

scripts/split_hex_occupancy_dataset.py

The script should:

  1. Read files from data/hex-occupancy/labeled/occupied and empty.
  2. Group files by original image name.
  3. Put 80% of image groups into train.
  4. Put 20% of image groups into val.
  5. Copy files into the Ultralytics folder layout.
  6. Print counts for each class in train and val.

Stop Rule

Do not train until the split prints nonzero counts for all four folders:

train/occupied
train/empty
val/occupied
val/empty

Recall

  • What is train used for?
  • What is val used for?
  • Why split by board image instead of random patch?
