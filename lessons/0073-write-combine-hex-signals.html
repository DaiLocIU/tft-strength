Write Combine Hex Signals

You want hex occupancy to stay as the primary signal, and champion box mapping to act as a second signal. The next script should combine both into one final occupied hex decision.

Win for this lesson: design combine_hex_signals.py so it compares two model opinions per hex and draws one review image.

The Pipeline

board crop
  -> hex occupancy classifier
  -> champion detector mapped to hexes
  -> combine signals
  -> final occupied hexes

Step 1: Create The File

vision-board-detector/scripts/combine_hex_signals.py

Step 2: Import Existing Work

Reuse your scripts. Do not reimplement hex cropping or champion detection.

from predict_hex_occupancy import predict_board_hex_occupancy
from map_champions_to_hexes import (
    assign_champions_to_hexes,
    predict_champion_boxes,
)

Step 3: Define One Hex Key

Both signals must speak the same language. The shared key is (row, column). 

hex_key = (row, column)

Step 4: Get Primary Signal

The occupancy classifier produces one prediction for every hex.

occupancy_predictions = predict_board_hex_occupancy(
    board_crop_path,
    HEX_OCCUPANCY_MODEL_PATH,
)

Step 5: Get Second Signal

The champion detector produces boxes. Convert those boxes to nearest hexes, then make a set of hex keys. 

champion_hex_keys = {
    (assignment["hex"]["row"], assignment["hex"]["column"])
    for assignment in champion_assignments
}

Step 6: Combine With A Simple Rule

Start simple. A hex is finally occupied if either signal says occupied.

final_occupied = occupancy_occupied or champion_mapped

Step 7: Track Why

Do not only store true or false. Store the reason, so debugging is possible.

both:
  occupancy says occupied
  champion detector maps champion here

occupancy_only:
  occupancy says occupied
  champion detector does not map here

champion_only:
  occupancy says empty
  champion detector maps champion here

empty:
  both say empty

Step 8: Draw Review Colors

green:
  both signals agree occupied

orange:
  occupancy only

blue:
  champion only

gray:
  empty

Step 9: Test One Image

Step 10: Review Before Batch

open outputs/combined-hex-signals

Decision Rule

if green is mostly correct:
  both models agree well

if orange is often correct:
  occupancy model catches cases champion detector misses

if blue is often correct:
  champion detector fixes occupancy misses

if orange or blue is often wrong:
  tune thresholds before trusting final output

First Version Goal

The first version should not be clever. It should make disagreement visible. Once you can see disagreement, you can decide better rules.
