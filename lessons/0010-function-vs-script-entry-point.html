Function Vs Script Entry Point

Your function can be correct, but the file still prints nothing unless something calls the function.

What Happened

You wrote a function:

def verify_labels_match_images(export_path, raw_dir):
    ...

That defines reusable behavior. But when you run the file, Python does not automatically call that function.

The Entry Point

Add this block at the bottom of the file:

if __name__ == "__main__":
    export_path = "exports/label-studio/board-100.json"
    raw_dir = "data/raw"

    matched, missing = verify_labels_match_images(export_path, raw_dir)

    print(f"matched: {len(matched)}")
    print(f"missing: {len(missing)}")

How To Run

Run from inside the project folder:

cd vision-board-detector
python3 scripts/check_dataset.py

Expected Output

matched: 100
missing: 0

What You Learned

  • A function defines behavior.
  • An entry point runs behavior.
  • Testing starts by making the smallest useful output visible.
