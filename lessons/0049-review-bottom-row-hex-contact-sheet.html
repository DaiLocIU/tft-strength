Review Bottom Row Hex Contact Sheet

You now have a contact sheet that draws the bottom row of seven hexes on every board crop. The next skill is not writing more code. The next skill is judging the geometry.

Goal: use one review image to decide which tuning value to change next.

Run The Review

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector
.venv/bin/python scripts/detect_hexes.py --bottom-row-contact-sheet

Open this file and inspect several crops, not only the first one:

outputs/review/board-hex-bottom-row-contact-sheet.png

Judge One Thing At A Time

  • If the whole row is too far left or right, tune width.
  • If the whole row is too high or low, tune height.
  • If each hex is too small or too large, tune radius.
  • If the empty space between hex borders is wrong, tune gap.

Do not change all four values at once. Change one value, rerun the contact sheet, then judge again. That gives you a tight feedback loop.

Try One Tuning Run

.venv/bin/python scripts/detect_hexes.py \
  --bottom-row-contact-sheet \
  width=13.4 height=90 radius=6.1 gap=3.4

In this script, gap means border-to-border empty space. The center-to-center step is calculated from the hex width plus that border gap.

Stop Condition

Stop tuning the bottom row when at least 10 random crops look acceptable. The row does not need to be perfect yet. It only needs to be stable enough to teach the next step: a second row with an offset.

Recall

  • Which value moves the whole row left or right?
  • Which value changes border-to-border spacing?
  • Why should you change only one value per run?
