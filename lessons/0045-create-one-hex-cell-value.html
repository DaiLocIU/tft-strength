Create One Hex Cell Value

You defined the type. Now create one actual value that follows that type.

A type is only the shape. A value is real data that uses the shape.

Add One Function

Under HexCell, write:

def create_first_hex_cell() -> HexCell:
    return {
        "row": 0,
        "column": 0,
        "center_x": 100.0,
        "center_y": 200.0,
        "radius": 40.0,
    }

Add A Tiny Script Entry

At the bottom of the file, write:

if __name__ == "__main__":
    cell = create_first_hex_cell()
    print(cell)
