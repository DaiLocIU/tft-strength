Export Task

vision-board-detector/exports/label-studio/board-100.json

What To Look For

Open the JSON file and find one labeled image. You are looking for these fields:

"value": {
  "x": 12.34,
  "y": 22.50,
  "width": 48.00,
  "height": 31.25,
  "rectanglelabels": ["board"]
}

The Important Meaning

Label Studio rectangle coordinates are percentages, not pixels. The top-left corner is x and y. The size is width and height. All four values are from 0 to 100.

Do Not Write Python Yet

First, inspect three labels manually. For each one, answer:

  1. What image file does this annotation belong to?
  2. Where is the rectangle's top-left corner?
  3. How wide and tall is the rectangle?
  4. Does rectanglelabels contain exactly board?
