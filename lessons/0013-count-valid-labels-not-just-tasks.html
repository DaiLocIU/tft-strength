Count Valid Labels, Not Just Tasks

A script can run and still answer the wrong question. Dataset validation means checking the structure you need for training.

Your Current Output

This proves the script checked 100 tasks. It does not prove each task has exactly one board rectangle.

The Better Question

For this first detector, each task should have exactly one rectangle labeled board.

Better Return Shape

Instead of returning only board_annotations, also return bad_labels.

if len(rectangles) == 1:
    valid_labels.append(original_filename)
else:
    bad_labels.append({
        "image": original_filename,
        "rectangle_count": len(rectangles),
    })

What You Learned

  • matched means the image file exists.
  • valid_labels means the annotation shape is correct.
  • A valid training example needs both.

Stop Point
