Rebuild Champion Dataset After Labeling 94 Images

You labeled 94 champion images. The next step is to turn that Label Studio export into the YOLO dataset folder that training actually reads.

Win for this lesson: rebuild data/champion-detector, confirm the train/val split, then start the next training run.

The Important Idea

Label Studio is where you create labels. YOLO does not train from the Label Studio project directly. YOLO trains from a dataset folder with images/train, images/val, labels/train, labels/val, and data.yaml.

Step 1: Use The New Export

Your new export is champion-94.zip. Use it explicitly.

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

.venv/bin/python scripts/prepare_champion_detector_dataset.py \
  --export exports/label-studio/champion-94.zip

Expected Output

train images: about 75
val images:   about 19
data yaml:    data/champion-detector/data.yaml

Step 2: Sanity Check The Dataset

Confirm that YOLO has image files and matching label files.

find data/champion-detector/images/train -type f | wc -l
find data/champion-detector/images/val -type f | wc -l
find data/champion-detector/labels/train -type f | wc -l
find data/champion-detector/labels/val -type f | wc -l

Step 3: Train Again

Start from the current champion detector because it already learned something. This is fine-tuning on the larger, better labeled batch. 

.venv/bin/yolo detect train \
  model=models/champion-detector.pt \
  data=data/champion-detector/data.yaml \
  imgsz=640 \
  epochs=100 \
  name=champion-detector-94

Step 4: Install The New Best Weight

After training finishes, copy the new best.pt into your app model path.

cp runs/detect/champion-detector-94/weights/best.pt \
  models/champion-detector.pt

Step 5: Test On Board Crops

.venv/bin/yolo detect predict \
  model=models/champion-detector.pt \
  source=outputs/board-crops \
  imgsz=640 \
  conf=0.5 \
  save=True \
  project=outputs/champion-detector \
  name=champion-94-board-crops-conf050

Decision

if most champions are detected:
  move to box-to-hex mapping

if many champions are still missed:
  collect another failure-focused batch

if wrong boxes appear often:
  inspect labels before adding more images
