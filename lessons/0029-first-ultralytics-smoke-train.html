First Ultralytics Smoke Train

Now test whether YOLO can read your dataset and start training.

Goal

This is not the real model yet. This is a smoke test.

Can Ultralytics load dataset.yaml?
Can it find images?
Can it find labels?
Can it complete one tiny training run?

Install

.venv/bin/python -m pip install ultralytics

Run One Tiny Train

.venv/bin/yolo detect train model=yolo11n.pt data=data/yolo/dataset.yaml epochs=1 imgsz=640

What Each Part Means

  • detect train: train an object detection model.
  • model=yolo11n.pt: start from a small pretrained model.
  • data=data/yolo/dataset.yaml: use your dataset config.
  • epochs=1: train for one short pass only.
  • imgsz=640: resize training images to 640px.

Expected Output

If it works, Ultralytics creates a run folder under:

runs/detect/train

Inside, the most important file is usually:

weights/best.pt

Do Not Judge Accuracy Yet

One epoch with train and validation using the same images only proves the pipeline runs. Accuracy comes later after a real train/val split and more training.
