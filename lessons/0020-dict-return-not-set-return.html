Dict Return, Not Set Return

Curly braces can mean two different things in Python. The colon decides whether it is a dictionary.

Set Syntax

return {
    matched,
    missing,
}

This is a set. It has values only. It does not have named fields.

Dictionary Syntax

return {
    "matched": matched,
    "missing": missing,
}

This is a dictionary. It has keys and values. This matches TypedDict.

TypedDict Rule

If the return type is VerifyResult, the return value must look like the interface:

class VerifyResult(TypedDict):
    matched: List[str]
    missing: List[str]
    valid_labels: List[str]
    bad_labels: List[str]

Next Habit

For required TypedDict fields, prefer bracket access:

matched = result["matched"]

Use .get() only when a key might be missing.
