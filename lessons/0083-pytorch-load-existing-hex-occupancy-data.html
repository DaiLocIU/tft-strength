Run This Inspection, Not Training

from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.Resize((160, 160)),
    transforms.ToTensor(),
])

dataset = datasets.ImageFolder("data/hex-occupancy/train", transform=transform)
loader = DataLoader(dataset, batch_size=4, shuffle=True)

images, labels = next(iter(loader))
print(dataset.classes)
print(images.shape)
print(labels.tolist())

Success means: two class names, four images in the batch, and four integer labels. If that works, your dataset crosses the boundary from “folders on disk” to “training-ready tensors.”
