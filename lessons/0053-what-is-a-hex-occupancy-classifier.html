What Is A Hex Occupancy Classifier?

You already know where the hexes are. The next model does not need to find champions on the whole screenshot. It only needs to answer one small question for each hex crop.

Goal: turn one cropped hex image into either occupied or empty.

Classifier Meaning

A classifier is a model that looks at one image and chooses one label from a fixed list. For your first hex model, the list has only two labels. 

input:  small crop around one hex
output: occupied or empty

This is different from YOLO detection. Detection asks, "Where are the objects?" Classification asks, "What kind of image is this?" 

detection:
  screenshot -> boxes around boards or units

classification:
  one hex crop -> occupied / empty

Why This Fits Your Project

You are already drawing hex centers. That means the location problem is partly solved. So do not ask a model to search the whole board yet. Crop each known hex and ask a smaller question. 

full screenshot
  -> board detector
  -> board crop
  -> 28 or 56 hex centers
  -> one crop per hex
  -> classifier predicts occupied / empty

Dataset Folder

Ultralytics classification datasets use folders as labels. Images inside occupied are positive examples. Images inside empty are negative examples. 

data/hex-occupancy/
  train/
    occupied/
    empty/
  val/
    occupied/
    empty/

No YOLO .txt label file is needed for this classifier dataset. The folder name is the label.

The Smallest Build Plan

  1. Use your existing board detector to crop boards.
  2. Use your current hex code to get each hex center and radius.
  3. Crop a square patch around each hex center.
  4. Save the patches into a temporary review folder.
  5. Manually move good examples into occupied and empty.
  6. Train a small classification model.
  7. Run prediction on new hex crops and draw occupied hexes.
