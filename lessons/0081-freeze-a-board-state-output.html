Freeze A Board State Output

Your visual result is good enough. The next step is to make the result useful to code: export one clean JSON board state for every board crop.

Win for this lesson: stop judging only screenshots and define the data your next feature will consume.

Why This Is Next

The review image answers: does this look right?. The JSON output answers: what units are on which hexes?. Team strength, traits, star levels, and tests all need the second answer.

Step 1: Keep The Current Models

models/champion-detector.pt
models/champion-identity-classifier.pt
models/hex-occupancy-classifier.pt

Do not retrain again until you find a clear failure group. The current pipeline is good enough to become a data producer.

Step 2: Add A JSON Output Folder

outputs/board-state/
  image_388.json
  image_389.json

Step 3: Export Units Only

Start with one record per occupied champion hex: 

{
  "row": 2,
  "column": 0,
  "champion": "warwick",
  "identity_confidence": 0.99,
  "champion_box_confidence": 0.88,
  "source": "both"
}

Step 4: Add An Identity Gate

Since you saw wrong names mostly below about 0.70, the JSON should not trust weak names. 

identity_confidence >= 0.70 -> champion name
identity_confidence <  0.70 -> "unknown"

Step 5: Verify Five Boards

Pick five hard boards, then compare their review image to their JSON file. This is your first board-state test set.

Star detection should be the next visual model after board-state JSON works. Otherwise you are adding another prediction before the current output is stable.
