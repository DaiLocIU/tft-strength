Create First Row Of Hex Centers

Now write the first real board function: create 7 hex cells in one row.

Today’s goal: return 7 HexCell values with columns 0 through 6.

The Idea

A TFT board row has 7 cells. In one row, all cells share the same center_y. Only center_x changes. 

column 0: start_x
column 1: start_x + gap
column 2: start_x + gap * 2
...
column 6: start_x + gap * 6

Add This Function

def create_hex_row(
    row: int,
    start_x: float,
    center_y: float,
    gap: float,
    radius: float,
) -> list[HexCell]:
    hexes: list[HexCell] = []

    for column in range(7):
        hexes.append(
            {
                "row": row,
                "column": column,
                "center_x": start_x + column * gap,
                "center_y": center_y,
                "radius": radius,
            }
        )

    return hexes

What This Teaches

range(7) gives column numbers 0 to 6. That matches the 7 board slots in one TFT row.

start_x + column * gap is the first important geometry formula in this project.
