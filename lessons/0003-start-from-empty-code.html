Start From Empty Code

This lesson changes the approach: you write the code, and the agent guides one small step at a time.

Rule: do not generate the full detector. Write one file, one idea, one test at a time.

What Exists Now

The project folder is intentionally empty except for folders:

vision-board-detector/
  data/raw/
  exports/label-studio/
  label_studio/
  scripts/
  src/board_detector/

First Thing You Will Write

You will write the Label Studio config by hand. Create this file:

vision-board-detector/label_studio/board_label_config.xml

Type this yourself:

<View>
  <Image name="image" value="$image"/>
  <RectangleLabels name="label" toName="image">
    <Label value="board"/>
  </RectangleLabels>
</View>

What This Teaches

This teaches the first computer vision workflow skill: defining what a human should label. If the label is vague, the model learns vague behavior.

Check Yourself

  1. What is the only label name?
  2. What does RectangleLabels mean we are drawing?
  3. Why are we not labeling champions yet?

After You Write It

Tell the agent: I wrote the Label Studio config. Then the next step is to create the smallest Python file that reads one Label Studio export.
