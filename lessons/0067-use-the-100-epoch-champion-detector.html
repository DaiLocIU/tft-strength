Use The 100 Epoch Champion Detector

After training, the next step is not to trust the model. The next step is to test the checkpoint on images and read the boxes with your eyes.

Win for this lesson: run the new model, inspect the saved images, then choose the next move from the result.

Mental Model

Training creates weights. Prediction uses those weights on images. Confidence is only the model's score for a box; it is not proof that the box is correct.

Step 1: Predict On Raw Images

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

.venv/bin/yolo detect predict \
  model=models/champion-detector.pt \
  source=data/raw \
  imgsz=640 \
  conf=0.25 \
  save=True \
  project=outputs/champion-detector \
  name=clean-100-raw-conf025

Step 2: Open The Output

open /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector/outputs/champion-detector/clean-100-raw-conf025

Step 3: Read The Result

good result:
  boxes cover real champion bodies
  few boxes on non-champions
  confidence often above 0.50

bad result:
  boxes cover UI, board, items, or effects
  many real champions are missed
  confidence is mostly below 0.25

Step 4: Try A Higher Threshold

If conf=0.25 gives too many wrong boxes, try stricter prediction.

.venv/bin/yolo detect predict \
  model=models/champion-detector.pt \
  source=data/raw \
  imgsz=640 \
  conf=0.50 \
  save=True \
  project=outputs/champion-detector \
  name=clean-100-raw-conf050

Decision Rule

if conf=0.50 still finds most champions:
  use this model in the next pipeline step

if conf=0.50 removes many real champions:
  use conf=0.25 and label more hard examples

if conf=0.25 is still messy:
  inspect labels before training again
