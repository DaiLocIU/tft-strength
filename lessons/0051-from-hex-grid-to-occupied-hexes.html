From Hex Grid To Occupied Hexes

You can now draw the 28 board hexes. The next target is not champion identity. The next target is occupancy: which hex has a unit on it?

Goal: turn one board crop into a list like row=2 column=4 occupied=True.

The Pipeline

Use two separate ideas. First, detect generic unit boxes on the board crop. Second, assign each detected unit to one hex. 

board crop
  -> 28 hex polygons
  -> generic unit boxes
  -> unit bottom-center points
  -> occupied hex ids

Why Bottom Center?

A unit's bounding box includes body, weapon, effects, and maybe health bar. The center of the full box may float above the board. The bottom-center point is closer to the unit's feet, so it is a better first guess for the hex the unit stands on. 

unit_x = (box_x1 + box_x2) / 2
unit_y = box_y2

First Data Shape

Add this shape later when you start coding occupancy:

class HexOccupancy(TypedDict):
    row: int
    column: int
    occupied: bool

Keep it boring. Do not store champion name, star level, item, or team yet. Those are later problems.
