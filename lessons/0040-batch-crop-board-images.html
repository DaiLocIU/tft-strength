Batch Crop Board Images

You can crop one detected board now. The next step is to run the same logic on every screenshot and produce a clean folder of board-only images.

Goal: turn data/raw/*.png into outputs/board-crops/*.png, while also printing which images failed detection.

The Idea

A model demo answers one question: “Can this image detect a board?” A pipeline answers a better question: “Can my project process all screenshots reliably?”

Use Path.glob("*.png") to find many image files. Sort the files so the output is stable every time you run it. Python's pathlib docs note that glob results are not guaranteed to be ordered, so sorting is a good habit. Python pathlib

The Function Shape

class BatchCropSummary(TypedDict):
    cropped: list[str]
    failed: list[str]


def crop_all_boards(raw_dir: str, output_dir: str) -> BatchCropSummary:
    ...

This return type is easier to debug than just printing text. Later you can ask: how many crops worked, which images failed, and which failures should go back to Label Studio.

Your Next Code

raw_path = Path(raw_dir)
output_path = Path(output_dir)

cropped: list[str] = []
failed: list[str] = []

for image_path in sorted(raw_path.glob("*.png")):
    detection = detect_board(raw_dir, image_path.name)

    if detection is None:
        failed.append(image_path.name)
        continue

    crop_file = output_path / image_path.name
    crop_board(str(image_path), detection, str(crop_file))
    cropped.append(image_path.name)

return {
    "cropped": cropped,
    "failed": failed,
}

Why This Is The Right Next Step

  • It tests the model on many screenshots, not only your favorite one.
  • It creates board-only images for the next detector, such as champions or units.
  • It gives you a failure list for the next active-learning loop.

Run Check

After you write it, run:

.venv/bin/python scripts/predict_board.py --all
