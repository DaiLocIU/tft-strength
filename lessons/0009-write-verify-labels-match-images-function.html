Write Verify Labels Match Images Function

Write one function whose only job is proving every Label Studio task can find its raw image.

Function Goal

The function should receive two paths:

export_path: path to board-100.json
raw_dir: path to data/raw

It should return two lists:

matched
missing

Write In Small Steps

  1. Open the JSON file.
  2. Loop over each task.
  3. Read task["data"]["image"].
  4. Extract the filename from the path.
  5. Remove the Label Studio hash prefix.
  6. Check whether the recovered filename exists in raw_dir.
