The File

path: data/yolo
train: images/train
val: images/train

names:
  0: board

Meaning

  • path: root folder of the YOLO dataset.
  • train: image folder used for training.
  • val: image folder used for validation.
  • names: class id to class name mapping.

Why Val Uses Train For Now

This is temporary. A real dataset should split images into train and validation sets. For the first smoke test, using the same folder lets you test the pipeline before adding more complexity.
