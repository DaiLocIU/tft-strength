Choose Champion Hex With Occupancy

You already combine hex occupancy and champion detection. Now refine the champion signal so large champions choose the occupied hex nearest their feet.

Win for this lesson: update get_champion_confidences_by_hex so champion boxes prefer occupied hexes under the box, but still work when occupancy misses.

The Problem

large champion box covers:
  row 2 column 3: occupied
  row 2 column 4: occupied

bottom-center point is closer to:
  row 2 column 4

final champion signal goes to:
  row 2 column 4

The Decision Rule

Do not ask whether the champion box is perfectly placed on an occupied hex. Ask a smaller question: among the occupied hexes under this box, which one is closest to the box bottom? 

if occupied hexes exist under champion box:
    choose nearest occupied hex to bottom-center
else:
    choose nearest hex to bottom-center

Step 1: Make Occupancy Easy To Query

def create_occupancy_predictions_by_hex(
    occupancy_predictions: list[HexOccupancyPrediction],
) -> dict[tuple[int, int], HexOccupancyPrediction]:
    return {
        hex_key(prediction["row"], prediction["column"]): prediction
        for prediction in occupancy_predictions
    }

Step 2: Check Box Area

Start with a simple area rule: a hex is under the champion box when its center is inside the box. 

def hex_center_is_inside_champion_box(hex_cell: HexCell, box: ChampionBox) -> bool:
    return (
        box["x1"] <= hex_cell["center_x"] <= box["x2"]
        and box["y1"] <= hex_cell["center_y"] <= box["y2"]
    )

Step 3: Choose The Best Hex

def find_best_hex_for_champion_box(...):
    point_x, point_y = box_bottom_center(box, image_height, foot_offset_ratio)

    occupied_hexes_under_box = [
        hex_cell
        for hex_cell in hexes
        if hex_key(hex_cell["row"], hex_cell["column"]) in occupied_hex_keys
        and hex_center_is_inside_champion_box(hex_cell, box)
    ]

    if len(occupied_hexes_under_box) > 0:
        return find_nearest_hex(point_x, point_y, occupied_hexes_under_box)

    return find_nearest_hex(point_x, point_y, hexes)

Step 4: Use It Per Box

for box in champion_boxes:
    assigned_hex = find_best_hex_for_champion_box(
        box,
        hexes,
        occupied_hex_keys,
        board_image.height,
        foot_offset_ratio,
    )
