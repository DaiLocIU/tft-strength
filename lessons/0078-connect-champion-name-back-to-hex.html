Step 1: Load Two Models

Keep the detector and classifier separate: 

champion_model = YOLO(CHAMPION_MODEL_PATH)
identity_model = YOLO(CHAMPION_IDENTITY_MODEL_PATH)

Step 2: Crop The Mapped Box

For every champion box, crop from the board image using x1, y1, x2, y2. 

crop = board_image.crop((box["x1"], box["y1"], box["x2"], box["y2"]))

This crop is the classifier input. The hex choice still comes from your existing bottom-center and occupancy logic.

Step 3: Classify The Crop

The classifier result uses result.probs.top1 for the class id and result.probs.top1conf for confidence. 

results = identity_model(crop, imgsz=160, verbose=False)
result = results[0]
class_id = int(result.probs.top1)
champion_name = result.names[class_id]
identity_confidence = float(result.probs.top1conf)

Step 4: Store Name In Evidence

Extend your champion evidence with two fields: 

{
  "box": box,
  "chosen_key": key,
  "champion_name": champion_name,
  "identity_confidence": identity_confidence
}

Step 5: Print The Final Result

The first useful output should be plain text, one line per occupied hex:
