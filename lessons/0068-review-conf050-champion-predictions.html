Review Conf 0.50 Champion Predictions

Your actual next step is to test whether the 100 epoch champion detector is usable at conf=0.5. This is a usability gate, not another training step.

Win for this lesson: decide whether the model is good enough to use, needs more labeled data, or has a label problem.

Why This Step Comes Next

A trained model is only useful if its predictions look correct on real screenshots. At conf=0.5, YOLO only keeps boxes it scores as fairly confident, so this test answers: “Can I trust this model enough for the next pipeline step?”

Command

cd /Users/inmac/Desktop/work-hard/tft-team-strength/vision-board-detector

.venv/bin/yolo detect predict \
  model=models/champion-detector.pt \
  source=data/raw \
  imgsz=640 \
  conf=0.5 \
  save=True \
  project=outputs/champion-detector \
  name=clean-100-raw-conf050

Open The Output

open outputs/champion-detector/clean-100-raw-conf050

Review 10 Images

  1. Count how many real champions are boxed.
  2. Count how many real champions are missed.
  3. Count wrong boxes on UI, items, effects, or background.
  4. Save the names of 3 bad images for the next labeling batch.

Decision

if most champions are boxed and wrong boxes are rare:
  use this model next

if many champions are missed but wrong boxes are rare:
  add more labeled champion examples

if many boxes are on wrong objects:
  inspect your labels before training more

if both misses and wrong boxes are high:
  label hard examples and retrain

The Key Lesson

More training is not the next step until you know what kind of failure you have. Missed champions need more examples. Wrong boxes often mean confusing labels or not enough negative variation.
