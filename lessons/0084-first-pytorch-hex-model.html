Your First PyTorch Hex Model

This lesson proves the smallest neural-network contract for your hex crops. It does not train a model.

Goal: [4, 3, 160, 160] → model → [4, 2].

Run It

cd vision-board-detector
.venv/bin/python scripts/test_hex_model.py

The script is test_hex_model.py. It loads four labelled hex crops, creates a model, and passes the batch through it once.

Read the Shapes

input:  [4, 3, 160, 160]
output: [4, 2]
  • 4 means four crop images in this batch.
  • 3 means the RGB colour channels.
  • 160 × 160 is the resized crop size.
  • 2 means one score for empty and one for occupied.

The Model Class

class HexOccupancyModel(nn.Module):
    ...

def forward(self, x):
    return self.model(x)

nn.Module says “this object is a PyTorch neural network.” forward defines how data moves through it. Calling model(images) calls model.forward(images).

Flatten Then Score

nn.Flatten()
nn.Linear(3 * 160 * 160, 2)

One image starts as [3, 160, 160]. Flatten converts it to [76800], because 3 × 160 × 160 = 76800. The linear layer turns those 76,800 values into two class scores.

[-0.3, 0.8]
 ↑      ↑
empty  occupied

The larger score would select occupied—but it is not a real prediction yet. The model’s weights are random until training changes them.
