Choose The Export Format

Label Studio can export many formats. For learning, choose the format that teaches the pipeline, not just the fastest shortcut.

Use JSON First

Export JSON first. This is Label Studio's common raw format, so you can inspect how your human labels are represented before training a model.

You should learn to recognize this shape:

"value": {
  "x": 10.5,
  "y": 23.0,
  "width": 46.2,
  "height": 31.4,
  "rectanglelabels": ["board"]
}

Use YOLO Later

Export YOLO when you want Label Studio to create training labels directly. YOLO is convenient, but it hides the conversion step you are trying to learn.

Do Not Use These Yet

  • JSON-MIN: useful later, but too stripped down for learning the full structure.
  • CSV/TSV: better for spreadsheet inspection, not first object detection training.
  • COCO: important in professional datasets, but heavier than needed for one class.
  • Pascal VOC XML: valid object detection format, but not the path we are taking.
