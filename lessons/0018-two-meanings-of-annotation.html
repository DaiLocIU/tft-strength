Two Meanings Of Annotation

In this project, the word annotation appears in two places. They are related to clarity, but they mean different things.

Label Studio Annotation

A Label Studio annotation is data created by a human. It says where the board is in an image.

{
  "annotations": [
    {
      "result": [
        {
          "type": "rectanglelabels",
          "value": {
            "x": 24.9,
            "y": 21.5,
            "width": 48.6,
            "height": 46.0,
            "rectanglelabels": ["board"]
          }
        }
      ]
    }
  ]
}

This kind of annotation trains the AI model.

Python Type Annotation

A Python type annotation is code written by a programmer. It says what type a variable, parameter, or return value should have.

def verify_labels_match_images(
    export_path: str,
    raw_dir: str,
) -> tuple:
    ...

This kind of annotation helps mypy, pyright, your editor, and your future self understand the code.

Mental Split

Label annotation  -> describes an image
Type annotation   -> describes code

In Your Script

This is Label Studio data:

task["annotations"]

This is Python typing:

task: TaskItem
