What Is An Epoch?

An epoch is one full pass through your training images.

Your Dataset

You currently have 100 labeled board images.

epochs=1

YOLO sees all 100 images one time.
epochs=20

YOLO sees all 100 images twenty times.

Why Start With 1?

One epoch is a smoke test. It answers:

Can YOLO read dataset.yaml?
Can YOLO find images?
Can YOLO find labels?
Can YOLO finish training?
Can YOLO save best.pt?

It is not meant to produce a good detector.

Why Try 20 Next?

Twenty epochs gives the model enough repeated practice to start learning the board shape and location.

1 epoch:  pipeline test
20 epochs: first learning test

The Risk

More epochs is not always better. If the model sees the same images too many times, it can memorize them instead of learning the general board pattern.

The Better Workflow

1. Run 1 epoch to test the pipeline.
2. Run 20 epochs to see if learning starts.
3. Split train and validation images.
4. Train longer only if validation improves.

Mental Model

epoch = one study round through all training examples
