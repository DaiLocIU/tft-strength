Annotation Vs Result

Label Studio has two different levels: the submitted annotation and the rectangle results inside it.

Why The Table Says 1

The table's 1 means this image has one submitted annotation object.

Why Detail Shows 2 Boards

Inside that one annotation object, there can be multiple rectangle results:

task
  annotations: [
    {
      result: [
        tiny board rectangle,
        real board rectangle
      ]
    }
  ]

Your Dataset Rule

For this project, each image should have:

1 task
1 annotation
1 board rectangle result
